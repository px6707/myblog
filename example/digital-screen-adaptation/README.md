# 数字化大屏适配示例

配套文章：`src/contents/posts/前端/数字化大屏适配：从画布缩放到图表响应.md` 和 `src/contents/posts/前端/数字化大屏适配方案选型：固定画布、响应式与混合布局.md`。

```bash
cd example/digital-screen-adaptation
npm install
npm run dev
```

运行后在画布底部切换三种方案：

| 方案 | 示例中的行为 |
| --- | --- |
| 固定画布 | 1920×1080 整体等比缩放，内部列宽保持设计坐标 |
| 混合布局 | 同样保留设计画布；窄视口时用 Grid 调整三列宽度并减少次要说明 |
| 完全响应式 | 取消画布缩放；Grid 按视口重排，Flex 填充面板，可滚动查看全部内容 |

改变浏览器窗口宽高，观察背景留白、布局档位和 ECharts。底部还可切换“普通 / 紧凑”信息密度；在窗口没有变化时切换，也能看到图表按**容器**尺寸更新。`npm run build` 会做 TypeScript 检查并构建。

示例用模拟数据，不接接口。基准画布为 1920×1080；极窄或竖屏窗口会进入紧凑档，但不承诺手机端完整呈现。生产项目需按目标设备确定内容取舍、字体下限和断点。
